# 📊 HR Analytics — ML Project

## 📌 Статус проекта
🚧 **Проект в процессе архитектурного рефакторинга**

Проект **полностью выполнен и завершён в формате Jupyter Notebook**

---

## 🧠 Описание проекта

**Сборный проект — 2. HR-аналитика**

Проект направлен на применение методов машинного обучения для анализа данных о сотрудниках компании.

🎯 **Основная цель проекта**:
- предсказать **уровень удовлетворённости сотрудников работой**;
- предсказать **вероятность увольнения сотрудников**.

Результаты проекта могут быть использованы HR-аналитиками для:
- снижения текучести кадров;
- раннего выявления рисков увольнения;
- оптимизации управления персоналом;
- удержания ценных сотрудников.

---

## 🧩 Задачи проекта

### 🔹 Задача 1: Предсказание уровня удовлетворённости сотрудника

Построить модель регрессии, которая предсказывает  
**уровень удовлетворённости сотрудника работой**
(`job_satisfaction_rate`, значение от 0 до 1)
на основе характеристик сотрудника.

Уровень удовлетворённости является важным индикатором,
влияющим на текучесть кадров.

---

### 🔹 Задача 2: Предсказание увольнения сотрудника

Построить модель бинарной классификации, которая предсказывает  
**вероятность увольнения сотрудника**
(`quit: yes / no`)
на основе тех же характеристик.

Это позволяет HR-отделу заранее реагировать на потенциальные проблемы
и принимать меры по удержанию сотрудников.

---

## 📁 Описание данных

### 📂 Данные для Задачи 1 (удовлетворённость)

- `train_job_satisfaction_rate.csv` — тренировочная выборка  
- `test_features.csv` — входные признаки тестовой выборки  
- `test_target_job_satisfaction_rate.csv` — целевой признак тестовой выборки  

### 📂 Данные для Задачи 2 (увольнение)

- `train_quit.csv` — тренировочная выборка  
- `test_features.csv` — входные признаки тестовой выборки  
- `test_target_quit.csv` — целевой признак тестовой выборки  

---

## 🧾 Описание признаков

### 🔹 Общие признаки

- `id` — уникальный идентификатор сотрудника  
- `dept` — отдел (категориальный признак)  
- `level` — уровень должности (категориальный признак)  
- `workload` — уровень загруженности (числовой признак)  
- `employment_years` — стаж работы в компании (числовой признак)  
- `last_year_promo` — было ли повышение за последний год (да/нет)  
- `last_year_violations` — были ли нарушения за последний год (да/нет)  
- `supervisor_evaluation` — оценка качества работы сотрудника (от 1 до 10)  
- `salary` — ежемесячная зарплата сотрудника  

### 🎯 Целевые признаки

- `job_satisfaction_rate` — уровень удовлетворённости (Задача 1)  
- `quit` — факт увольнения (Задача 2)

📌 Важно

Вся логика проекта и финальные выводы полностью реализованы в ноутбуке
`HRAnalytics.ipynb`.

Папка `src/` отражает **пошаговый перенос ноутбучного решения
в production-ориентированную архитектуру**.

- обработка пропусков и категориальных признаков;

- оценка качества моделей на тестовых данных.
